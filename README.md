# Kalkulator wyceny glazurnika

Narzędzie do wyceny pracy glazurnika. Zaznaczasz, co jest do zrobienia na inwestycji (płytki, przygotowanie podłoża, wnoszenie, instalacje, biały montaż, otwory, fugowanie, ukosowanie), podajesz dane dojazdu, a kalkulator liczy:

- wycenę „na zero” (robocizna + paliwo),
- liczbę dni pracy i przejazdów (automatycznie lub z kalendarza),
- po przesunięciu suwaka ceny: ile zostaje, dniówkę, godzinówkę i zarobek w % względem wyceny na zero.

Wszystkie stawki i czasy można zmienić w sekcji „Cennik i czasy”. Dane zapisują się tylko w przeglądarce.

Strona: https://paterski.github.io/kalkulator-glazurnika/
